#  React Module Projects

Ce dépôt regroupe plusieurs projets réalisés en React dans le cadre d’un module de formation.

---

#  Projets inclus

##  Contact App (React + NodeJS)
Application de gestion de contacts avec backend.

### Fonctionnalités :
- Ajouter un contact
- Modifier un contact
- Supprimer un contact
- Afficher les contacts
- Backend NodeJS + API REST

---

##  Todo App (React)
Application de gestion de tâches.

### Fonctionnalités :
- Ajouter une tâche
- Supprimer une tâche
- Marquer comme terminée
- Gestion locale (useState)

---

##  Blog App (React + NodeJS + JWT) 

Mini réseau social / blog complet avec authentification.

### Fonctionnalités :
- Inscription / Connexion utilisateur
- Authentification JWT
- Création d’articles
- Modification d’articles
- Suppression d’articles
- Affichage de tous les articles
- Recherche et tri
- Routes protégées

### Technologies :
- React (Vite)
- React Router
- NodeJS / Express
- JWT
- bcrypt
- Axios
